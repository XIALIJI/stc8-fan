## 一、怎么编译（已经在用）

双击根目录 build.cmd，默认编译**实验 3（七模式智能风扇）**。

    build.cmd            编译实验 3
    build.cmd 2.3        编译实验 2.3（超声波测距）
    build.cmd 1.1        编译实验 1.1（三色 LED）

或用 PowerShell：

    powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 3

支持的实验：1.1  1.2  2.1  2.2  2.3  2.4  2.5  2.6  2.7  2.8  3。
产物是 build\exp_x_x.hex，全部 11 个我都验证过能生成。

> 编译脚本内部做的事：A51 汇编启动文件 → C51 逐文件编译 → BL51 链接（RAMSIZE(256)）→ OH51 转 hex。
> 链接时的 L16 UNCALLED SEGMENT 是「有函数没被这个实验调用」的提示，不是错误，忽略即可；C51 编译本身是 0 警告 0 错误。

## 二、怎么下载到板子（STC-ISP，待你自己装）

1. 装 STC-ISP（[stcai.com](https://www.stcai.com/) 或实验室给的压缩包，绿色版解压到 D 盘，别放 C 盘）。
2. 打开 STC-ISP → 芯片型号选 **STC8H8K64U**。
3. 打开 build\exp_x_x.hex。
4. **输入频率选 24MHz**（代码按 24MHz 1T 写的，选错时钟全部乱套）。
5. 点「下载/编程」，然后给板子重新上电完成下载。

## 五、关键设计（报告里能写的东西）

1. **舵机为什么不用硬件 PWM8**：PWM8(P2.3) 和电机 PWM6(P2.1) 在 PWMB 组里，共享同一个周期寄存器——电机要 1kHz、舵机要 50Hz，硬件上没法共存。所以电机用硬件 PWM6，**舵机改用软件 PWM（T2 定 20ms 周期 + T3 定脉宽）**。如果老师给的框架里舵机是硬件 PWM8，把 m_servo.c 换回硬件版即可。

2. **任务节拍 T4**：T4 做 1ms 系统机（TASK_TIMER=4），T0 让给超声波（16 位自动重装 1T）。四个中断向量 T0=1、T2=12、T3=19、T4=20。

3. **DS18B20 时序**：1-wire 读写位的时候关全局中断（EA=0），转换等待 750ms 时开中断，避免 T4 节拍把时序打乱。

4. **自动温控档位**：ΔT = 温度整数 − 阈值；ΔT≤0→停，0<ΔT<2→30%，2≤ΔT<5→60%，ΔT≥5→90%。

5. **柔风**：距离 ≤20cm→30%，≥80cm→100%，中间线性插值。

6. **光控**：三个子模式（亮灯 / 停扇 / 关闭），参数全局生效；停扇在「光敏高8位 ≥ 阈值」时强制占空比 0，无锁存（低于阈值自动恢复）。

7. **EEPROM**：0xF000 起，+0 Magic(0xAA)、+1 温度阈值、+2 光控子模式、+3 亮灯阈值、+4 停扇阈值、+5 摆头使能、+6 摆头幅度。上电 Magic 校验，无效回默认。下载时 STC-ISP 里要把 EEPROM 设 ≥1KB。

8. **内存**：SMALL 模型 + RAMSIZE(256) 用满 256 字节 RAM（DATA 直接寻址 94 字节，任务表放 idata）。

## 六、和指导书不一样的地方（要跟老师说明）

| 点 | 指导书 | 本工程 | 原因 |
| --- | --- | --- | --- |
| 舵机 | 硬件 PWM8 | 软件 PWM(T2/T3) | PWM6/8 同组周期冲突，见上 |
| T 模式 | 提到 12T | 按 24MHz 1T | STC8H 常配，且 T0 计距用 1T 更准 |
| 业务文件 | .c/.h 成对 | 只有 .c | 各实验只导出 User_Init + 任务表，声明在 task.h/main.c，不需要 .h |

## 七、上板前必验清单

> **已上板验证**：实验 1.1（三色 LED 流水）——2026-11-20 通过 CP2102 / COM7 烧录成功，板级运行正常。

- 舵机 50Hz 软件 PWM 的脉宽实测（500～2500µs ↔ 0～180°）。
- 电机 PWM6 频率与占空比、IN1 电平。
- 超声波测距数值（T0 计数 1412 ticks/cm 按声速 340m/s，可现场微调）。
- 光敏 ADC 高 8 位阈值 100 是否合适（按现场光照调）。
- EEPROM 读写/擦除是否成功、掉电保存（需 STC-ISP 配 EEPROM 区）。
